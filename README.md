# MaoneArt Code — Mobile Visual Studio Code IDE for Android

> Desktop-grade VS Code experience directly on your Android phone or tablet.

## 🚀 Fitur Utama
- **Core Visual Studio Code**: Berjalan di atas engine resmi VS Code (v1.145.2) dengan UI asli desktop.
- **Open VSX Marketplace**: Mendukung seluruh ekstensi populer (Python, Pylance, Prettier, Tailwind CSS, ESLint, GitLens, Cline, Roo Code, dll).
- **Integrated Terminal**: Terintegrasi langsung dengan shell Linux Termux (Node.js, Git, Python, Bash, GCC).
- **Physical Keyboard Shortcut Interception**: Menangkap dan memetakan pintasan `Ctrl+S`, `Ctrl+P`, `Ctrl+Shift+P`, `Ctrl+W`, `Ctrl+B`, `Ctrl+\`` tanpa dimakan sistem Android.
- **Mobile Accessory Key Bar**: Tombol cepat sentuh (`ESC`, `TAB`, `CTRL`, `ALT`, `F1`, `Simpan`, `Terminal`, `Berkas`).
- **Workspace Lokal**: Langsung membuka repositori dan folder proyek di `/sdcard/www`.

## 📦 Cara Menjalankan
1. Di Termux, jalankan perintah:
   ```bash
   code
   ```
2. Buka aplikasi **MaoneArt Code** di layar HP Android Anda.
